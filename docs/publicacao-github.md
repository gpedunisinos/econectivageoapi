# Publicação inicial no GitHub

O código desta publicação corresponde à revisão `37b61c6` da branch `main` da API Geo mantida no Bitbucket. Os arquivos versionados foram copiados sem importar o histórico privado, arquivos locais de ambiente, credenciais ou bases geográficas.

A apresentação da API e os exemplos de integração foram atualizados no README. A implementação, os contratos e as migrações da versão de origem foram preservados.

Esta publicação não altera o serviço geográfico implantado nem o PostGIS em produção. Os scripts SQL são definições e normalizações do schema; não são dumps de banco. As bases geográficas devem ser obtidas das fontes oficiais e importadas no ambiente de destino.
